# LOOP — Steam発売に向けた計画

## 技術方針

**今の試作（HTML / JavaScript）をそのまま製品のコードに育てます。**

- PC版は Electron（ゲームをアプリとして包む仕組み）で Windows / Mac / Linux（Steam Deck）向けに書き出す
- Steamの機能（実績・クラウドセーブ・オーバーレイ）は steamworks.js でつなぐ
- 当初の候補だった Godot から変える理由
  - 遊びの部分はすでに JavaScript で動いており、作り直しが不要
  - 描画（Canvas）と音（Web Audio）は今の仕組みで足りる
  - ブラウザ版をそのまま体験版や宣伝に使える
- 土台は `desktop/` に用意済み（v1.4）。起動方法・配布方法・Steamworks 側の設定は desktop/README.md
- Web の技術で作られて Steam で売られているゲームは珍しくない（例：CrossCode は NW.js 製）

## Steam の手続き（ご本人の作業）

1. Steamworks のパートナー登録（本人確認・税・銀行情報）
2. Steam Direct の登録料 100ドル（1作品ごと。売上が1,000ドルを超えると返金）
3. ストアページを作り「近日登場」として公開（発売の少なくとも2週間前。早いほどウィッシュリストが集まる）
4. ストアページとビルドの審査（数日かかる）
5. 新しいパートナーは、登録料の支払いから30日たたないと発売できない

※ 手続きの細かい条件は変わることがあるため、登録時に Steamworks の公式ドキュメントで確認してください。

## ストアページの素材

- `store/STORE_TEXT.md`：短い紹介文・詳しい説明（3言語）、タグ案、動作環境案、画像の一覧
- `store/out/`：カプセル画像7種（下書き）とスクリーンショット5枚。`node store/render.cjs` で再生成
