# LOOP（仮題）

ミニマルな音楽ローグライク。4段×8拍のループ盤面にタイルを置き、周回ごとに変化する盤面で「熱量」を稼ぐ。

## 試作 v0.1（prototype.html）で検証すること

- 周回ごとに変化するタイル（クレッシェンド、エコー、ゴースト）が組み合わせとして楽しいか
- ノイズ（欲張るほど失敗に近づく）とフェードアウト（早く止めるとコイン）の駆け引きが成立しているか
- 「もう1回遊びたい」と思えるか

## 試作の仕様

- 4ラウンド（目標 150 / 400 / 850 / 1300）、4ラウンド目はボス「メトロノーム」（偶数拍の熱量0）
- 1ラウンド＝8拍×4周。同じ拍のタイル数で倍率（+0.5倍ずつ）
- 毎周ランダムな1列がスポットライト（×2）
- ノイズ40で失敗
- タイル12種、ラウンド間にショップ（4択・入れ替え◎1）

## 製品版の想定（10時間ボリューム）

タイル約100種、装置約30種、楽器セット6種、ボス曲12種、難易度10段階、エンドレス、毎日の挑戦、アルバム（作った曲の保存）。開発期間の目安は約4ヶ月。
