# LOOP（仮題）

ミニマルな音楽ローグライク防衛ゲーム。4レーン×8拍のループ盤面がそのまま武器になり、戦い方の結果として自分の曲が鳴る。

## 設計方針：強さと音を分ける

| 層 | 決めること | 強さへの影響 |
|---|---|---|
| 戦闘 | どのタイルを、どのレーン・どの拍に置くか | すべてここで決まる |
| 音 | 各タイルの音程、調、音階（将来は音色・強弱も） | なし |
| スタジオ（予定） | 集めたタイル・音色で自由に作曲・書き出し | なし |

- 音の選択は数値に影響しないので、バランス調整は戦闘層だけで済む
- 何もしなくても音程は自動で調に合う。作り込みたい人は自由に変えられる
- 新しい音色やタイルは攻略で解放する予定（作曲勢にも攻略の動機を作る）

## 試作 v0.2（prototype.html）

- 5ステージ（4ステージ＋ボス）。敵4種（ドット・ダッシュ・ブロック・ミニ）とボス「テンポ泥棒」（レーン移動、拍の封印、ミニ召喚）
- タイル13種、装置4種（2・4ステージ後に選択）
- ノイズが上限に達すると1小節オーバーヒート（演奏停止）
- 演奏中もタイルの置き直し可能。置いたタイルを選ぶと音程を変更できる
- 調12種×音階6種、試聴モード

### バランスの目安
単純な自動配置ボット（報酬は先頭を選ぶだけ、途中で置き直さない）で12回中4回クリア。考えて置き直す人間ならもっと勝てる想定。

## v0.3 の追加

- 置き直しの制限：ステージ開始前は自由。演奏中の置き直しはポイントを1使い、1小節ごとに1回復（最大3）

## v0.9 の追加（BGM と見た目）

- BGM 6種類（夜明け・ローファイ・深海・ネオン・祭囃子・嵐）。音源ファイルではなくその場で生成
- BGM は盤面と同じ時計・調・音階・コード進行で鳴るので、プレイヤーが作った曲と必ず噛み合う
- 盤面に多い楽器のパート（打楽器・低音・和音・旋律）は BGM 側が自動で音量を下げて場所を譲る
- 敵の数や接近具合に応じて BGM のパートが増え、盛り上がる（ボス戦は最大）
- ステージごとに候補3曲＋なし。選んだ音階に合う曲を「おすすめ」表示。選んだ曲は次のステージでも候補にあれば引き継ぐ
- メニューに BGM の音量を追加
- 見た目：音の波形表示（スペクトラム）、拍に合わせて脈打つスピーカー、撃破時の粒子、攻撃したタイルの発光

## v1.1 の追加（スタジオ・コントローラー対応）

- スタジオ：敵の出ない自由作曲モード。パレットのタイルは何枚でも置ける。テンポ（60〜160 BPM）、調・音階・BGM 6種を自由に選べる。作った曲はアルバムに保存
- スタジオで使えるタイルは、3つの楽器セットの初期タイル（9種）＋挑戦で一度でも手に入れたタイル。遊ぶほど作曲の幅が広がる

- コントローラー操作（標準配置）：十字キー／左スティックで移動、A 置く・持つ、B 取り消し、X 戻す、Y 試聴、LB/RB タイル選択、LT/RT 音程、START 開始、BACK メニュー
- 盤面の編集処理を1か所にまとめ、マウス・タッチ・キーボード・コントローラーで同じ動きになるようにした
- PC画面：右の列が長いときは列の中だけスクロールし、1280×720 でも画面全体はスクロールしない
